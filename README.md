# 💣 MINE RUSH (지뢰러시)

> 도파민이 터지는 하이퍼캐주얼 지뢰찾기. 클래식 지뢰찾기의 두뇌 게임성 + 모던 하이퍼캐주얼의 손맛/타격감.

**빌드 없음 · 완전 자립형 단일 페이지.** `index.html`을 브라우저로 열기만 하면 끝. (외부 라이브러리/폰트/오디오 파일 0개)

## ▶️ 실행

```bash
# 그냥 파일을 열거나
open index.html
# 또는 로컬 서버
python3 -m http.server 8000   # http://localhost:8000
```

## ✨ 핵심 재미 (왜 도파민이 터지는가)

- **콤보 시스템** — 안전 칸을 연속으로 열수록 배율(×1 → ×10)이 오른다. 곡선이 게임 전체에 걸쳐 살아있게 튜닝.
- **타격감(Juice)** — 3D 플립 오픈, 파티클 버스트, 지뢰 밟으면 화면 흔들림, 승리 컨페티.
- **합성 사운드** — Web Audio로 실시간 합성(파일 없음). 콤보가 오를수록 피치 상승, 승리 팡파레.
- **햅틱** — 모바일 진동 피드백.
- **기록/스트릭** — 난이도별 최고점수·최단시간·연승을 localStorage에 저장.

## 🎮 조작

| 입력 | 동작 |
|------|------|
| 좌클릭 / 탭 | 칸 열기 |
| 우클릭 / 길게 누르기 | 🚩 깃발 |
| 🚩 버튼 | 모바일 깃발 모드 토글 |
| 숫자칸 더블클릭 / 클릭 | 자동 열기(chord) |
| 난이도 | 쉬움(9×9·10) / 보통(16×16·40) / 어려움(16×30·99) |

## 🏗 개발 프로세스 (멀티 에이전트)

이 프로젝트는 **기획 → 병렬 개발팀 → PM 검수 → 2차 디벨롭** 파이프라인으로 제작됐다.

1. **기획 (PM/기획자)** — 컨셉·트렌드 정의, `docs/기획서.md`에 화면 DOM 계약과 모듈 인터페이스 계약을 명세해 병렬 작업 충돌을 원천 차단.
2. **개발팀 3인 병렬 투입** (각자 별도 파일 담당)
   - 게임 엔진 개발자 → `js/engine.js` (셀프테스트 10종 통과)
   - 비주얼/UX 디자이너 → `css/style.css`
   - 도파민/FX 엔지니어 → `js/effects.js`
   - 리드가 통합 컨트롤러 `js/game.js` + `index.html` 작성.
3. **통합 & 브라우저 검증** — Playwright로 실제 플레이(플러드필/콤보/난이도/오버레이) + 콘솔 에러 0 확인.
4. **최종 PM 검수** — 실제 런타임 스크린샷 + 코드 기반 12개 개선점 punch-list 도출.
5. **2차 디벨롭** — punch-list 반영.

### PM 검수 → 2차 디벨롭에서 고친 것들

| # | 문제 | 조치 |
|---|------|------|
| P0 | 첫 클릭에 콤보/점수가 ×10 만렙 → 도파민 곡선 소진 | 콤보를 flood 칸 수가 아닌 **클릭 액션 기준**으로 재설계 (첫 클릭 ×2 → 점진 상승) |
| P1 | 콤보 유지창 1.5초가 어려운 난이도에서 사고할 때마다 리셋 | 유지창 5초로 확대 |
| P1 | score "pop" 클래스만 토글되고 CSS 규칙 부재 | `scorePop` 키프레임 추가 + `.stat--score` 카드에 적용 |
| P1 | 보드 wrap 정사각 고정 → 어려움 보드 찌그러짐/빈공간 | wrap 종횡비를 그리드 실제 비율에 동기화 |
| P1 | `min-height:32px`가 밀집 보드를 직사각형으로 왜곡 | `.board--dense`로 넓은 보드에서 해제 |
| P2 | 종료 후에도 닫힌 칸이 hover/클릭되는 것처럼 보임 | 게임오버 시 보드 `data-frozen` freeze |
| P2 | HUD 타이머(초)와 기록(m:ss) 포맷 불일치 | 전 구간 `fmtTime` 통일 |
| P2 | 남은 지뢰 음수 표시가 버그처럼 보임 | 음수일 때 경고색 표시 |
| P2 | 셀 키보드 포커스 링 없음 | `.cell:focus-visible` 추가 |
| P2 | 오버레이가 접근성 다이얼로그 아님 | `role="dialog"`, 포커스 이동, Esc=다시하기, aria-live |
| P2 | 모바일 롱프레스가 숫자칸 chord 탭을 삼킴 | 닫힌 칸에서만 롱프레스 무장 + 최초 코치 힌트 |
| P2 | 음소거 미저장 / 뷰포트 확대 차단(WCAG) | 음소거 localStorage 저장·복원, `user-scalable=no` 제거 |
