# 🎮 MINE RUSH (지뢰러시) — 기획서

> "지뢰찾기는 지루하다"는 편견을 깬다. **도파민이 터지는** 하이퍼캐주얼 지뢰찾기.

## 1. 개요

| 항목 | 내용 |
|------|------|
| 제품명 | **MINE RUSH** (지뢰러시) |
| 장르 | 캐주얼 퍼즐 (클래식 지뢰찾기 + 게이미피케이션) |

## 2. 컨셉 — "왜 도파민이 터지는가"

클래식 지뢰찾기는 재미의 90%가 마지막 승리 순간에 몰려 있다. MINE RUSH는 **모든 클릭마다 보상**을 준다.

1. **콤보 시스템** — 빠르게 연속으로 안전 칸을 열면 콤보가 쌓이고 점수 배율이 오른다 (×1 → ×2 → ×3...). 하이퍼캐주얼의 핵심 도파민 루프.
2. **타격감(Juice)** — 칸이 3D로 뒤집히고, 열릴 때 파티클이 튀고, 지뢰를 밟으면 화면이 흔들린다.
3. **사운드** — 열 때마다 음이 올라가는 상쾌한 사운드(콤보에 따라 피치 상승), 승리 팡파레.
4. **햅틱** — 모바일에서 진동 피드백.
5. **연출** — 승리 시 색종이(컨페티) 폭발, 신기록 배지.
6. **스트릭/기록** — 최고 기록, 승리 스트릭을 localStorage에 저장해 재방문 동기 부여.

## 3. 디자인 방향 (2025-2026 트렌드)

- **다크 네온 + 글래스모피즘**: 어두운 배경, 반투명 유리 패널, 네온 글로우.
- **비비드 그라디언트**: 보라→핑크→시안 계열의 생동감 있는 그라디언트 포인트.
- **벤토(Bento) 레이아웃**: 상단 HUD를 카드형으로 정돈.
- **마이크로 인터랙션**: 호버/프레스 시 스프링 애니메이션, 부드러운 이징.
- **숫자별 컬러 코딩**: 인접 지뢰 수(1~8)를 네온 컬러로 구분해 가독성 + 심미성.

## 4. 핵심 기능 (MVP)

- [x] 3단계 난이도: **쉬움**(9×9, 지뢰10), **보통**(16×16, 40), **어려움**(16×30, 99)
- [x] 첫 클릭 안전 보장 (첫 클릭 칸 + 주변 8칸엔 지뢰 없음)
- [x] 좌클릭 = 열기 / 우클릭(모바일: 깃발모드 토글) = 깃발
- [x] 자동 확장(flood-fill): 0인 칸 클릭 시 인접 0 영역 자동 개방
- [x] 코드(chord): 숫자 칸에서 인접 깃발 수가 숫자와 같으면 나머지 자동 개방
- [x] 승리/패배 판정, 지뢰 전체 공개
- [x] 타이머, 남은 지뢰 카운터
- [x] 콤보 시스템 + 점수 + 콤보 게이지
- [x] 사운드/파티클/화면흔들림/컨페티/햅틱
- [x] 최고 점수·최단 시간 저장 (난이도별)
- [x] 모바일 완전 반응형 + 깃발모드 토글 버튼

### 셀(cell) 계약
각 셀은 `<button>` 요소, 클래스 `cell`. 상태는 **data 속성**으로 표현(디자이너가 이걸 기준으로 스타일링):
- `data-revealed="true|false"`
- `data-flagged="true|false"`
- `data-mine="true|false"` (게임오버 시에만 노출)
- `data-adjacent="0..8"` (열린 칸의 인접 지뢰 수; 0이면 빈칸)
- `data-exploded="true|false"` (밟은 지뢰)
- 텍스트: 인접 수(1~8) 또는 💣/🚩
그리드는 CSS `--cols` 변수로 컬럼 수를 받음: `.board { grid-template-columns: repeat(var(--cols), 1fr); }`

## 6. 모듈 인터페이스 계약 (개발자 공용)

### 6.1 `js/engine.js` — 게임 엔진 (순수 로직, DOM 없음)

```js
// 전역 window.MinesweeperEngine 로 노출 (ES module 아님, <script> 로드)
class MinesweeperEngine {
  constructor(rows, cols, mineCount)   // 보드 크기·지뢰 수
  get rows() / get cols() / get mineCount()
  get state()          // 'ready' | 'playing' | 'won' | 'lost'
  get flagsUsed()      // 사용한 깃발 수
  get remainingMines() // mineCount - flagsUsed (음수 가능)
  get revealedCount()

  cell(r, c)  // -> { revealed:bool, flagged:bool, mine:bool, adjacent:int, exploded:bool }

  // 첫 reveal 시 지뢰를 배치(첫 칸+주변8칸 제외). 이후 flood-fill.
  // return: {
  //   ok: bool,                       // 클릭이 유효했는지(닫힌·비깃발 칸)
  //   revealed: [{r,c,adjacent,mine}],// 이번에 새로 열린 칸들
  //   state: 'playing'|'won'|'lost',
  //   hitMine: {r,c}|null,            // 밟은 지뢰(패배 시)
  //   firstClick: bool
  // }
  reveal(r, c)

  // 깃발 토글. return { flagged:bool, ok:bool }
  toggleFlag(r, c)

  // 코드(chord): 열린 숫자칸 주변 깃발수==숫자면 나머지 open.
  // reveal 과 동일한 반환 형태. 조건 불충족 시 {ok:false, revealed:[]}.
  chord(r, c)

  // 패배 시 모든 지뢰 위치 반환: [{r,c}]
  allMines()

  reset()  // 같은 크기로 새 게임
}
window.MinesweeperEngine = MinesweeperEngine;
```
**요구사항**: 첫클릭 안전, flood-fill(0 확장), 승리=지뢰 아닌 칸 모두 open, 정확한 인접수 계산, 이미 열린/깃발 칸 클릭 무시. 순수하고 테스트 가능하게. 파일 하단에 `console.assert` 기반 자가 셀프테스트 몇 개 포함(주석 처리 X, 조용히 통과).

### 6.2 `js/effects.js` — 타격감/도파민 엔진

```js
// 전역 window.Effects 로 노출
window.Effects = {
  init(canvas),                 // fxCanvas 연결, 리사이즈 핸들링

  // 사운드 (Web Audio, 외부파일 X, 최초 사용자 제스처에서 resume)
  unlockAudio(),                // 첫 클릭에서 호출
  setMuted(bool),
  playReveal(comboLevel),       // 콤보가 높을수록 피치↑ 상쾌한 음
  playFlag(),
  playExplosion(),              // 지뢰
  playWin(),                    // 팡파레
  playCombo(level),             // 콤보 상승 효과음

  // 파티클 — screenX/Y는 fxCanvas 좌표
  burst(x, y, opts),            // 칸 열림 시 작은 파티클 튐 (색상=인접수 컬러)
  confetti(),                   // 승리 시 화면 전체 색종이

  // 화면 연출
  shake(intensity),             // 지뢰 밟으면 화면 흔들림 (document.body 또는 #app)
  haptic(pattern),              // navigator.vibrate 래퍼(미지원시 무시)
};
```
**요구사항**: 60fps 목표, requestAnimationFrame 루프 하나로 파티클 관리, 자원 누수 없음. 사운드는 OscillatorNode/GainNode로 합성(자립형). 접근성: prefers-reduced-motion 존중(흔들림·과한 애니 축소).

## 7. 콤보 & 점수 규칙

- 안전 칸을 열 때마다 콤보 타이머(1.5초) 리셋. 연속으로 열면 콤보 유지.
- 한 번의 reveal로 여러 칸이 열리면(flood-fill) 열린 칸 수만큼 콤보 상승 가속.
- 점수 = Σ (열린칸 1개당 10점 × 현재 콤보배율). 콤보배율 = 1 + floor(combo / 5), 최대 ×10.
- 콤보 게이지가 가득 차면 배율 상승 연출(사운드+글로우).
- 지뢰 밟으면 콤보 리셋.
- 승리 보너스 = 남은시간·난이도 기반.

## 8. 완료 기준 (Definition of Done)

1. 3난이도 모두 정상 플레이(첫클릭 안전, flood-fill, chord, 승/패).
2. 데스크톱(마우스 좌/우클릭) + 모바일(탭/깃발토글) 동작.
3. 콤보·점수·타이머·기록 정상.
4. 사운드/파티클/흔들림/컨페티/햅틱 동작 + 음소거 토글.
5. prefers-reduced-motion 및 반응형 레이아웃.
6. 콘솔 에러 0. 엔진 셀프테스트 통과.
